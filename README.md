Repositório destinado aos códigos, anotações e exercícios práticos desenvolvidos pelo **Grupo 01** durante a **Aula 01**.

## 📋 Sobre o Projeto

Este repositório tem como objetivo centralizar a entrega inicial da primeira aula, facilitando a colaboração entre os integrantes do grupo e o acompanhamento das atividades propostas.

## 🎯 Objetivos da Aula 01

- Configuração do ambiente de desenvolvimento e controle de versão (Git/GitHub).
- Estruturação inicial do repositório do grupo.
- Execução dos primeiros exercícios e testes práticos.
